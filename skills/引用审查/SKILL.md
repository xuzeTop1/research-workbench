# 引用审查

## 核心护栏

| 规则 | 说明 |
|------|------|
| 只诊断不治疗 | 输出问题清单+建议动作，绝不替用户修改引用内容 |
| AI 验证有局限 | 联网搜索可能不可达（paywall/403），标记为"无法在线验证"而非"不存在" |
| 用户最终负责 | 报告顶部明确声明"本审查结果仅供参考，引用真实性由作者本人负责" |
| 不自动增删引用 | 不添加新引用、不删除现有引用，只"建议"用户考虑增删 |

## 声明块（每次输出顶部必须包含）

```
⚠️ 引用审查免责声明

本审查由 AI 执行，存在以下已知局限：
1. 联网搜索无法访问付费墙后的内容（IEEE Xplore 全文、ACM DL 部分文章）
2. 可能无法区分标题相似但实际不同的论文
3. 格式合规判断可能存在文化差异误判
4. 缺失引用检测基于 AI 知识覆盖范围，可能有盲区

最终引用真实性、准确性、完整性由论文作者全权负责。
建议：对每条 "无法确认" 项，亲自到原始数据库核实。
```

## 六维度检查

### 维度 1: 存在性

- 通过 WebSearch 验证论文标题、作者、出处
- 可访问源：Google Scholar / arXiv / Semantic Scholar / DBLP
- 不可达时标记 `[无法在线验证 - 请作者手动确认]`

### 维度 2: 格式合规

按目标期刊格式体系检查（从 journal_profile 读取）：
- ACM Reference Format（TOIS 用）
- GB/T 7714（中文期刊）
- IEEE（CS 会议期刊）
- APA 7th（社会科学）

### 维度 3: 交叉完整性

- 正文引用标注 ↔ 参考文献列表一一对应
- 编号连续性
- 按出现顺序排列（如要求）

### 维度 4: 覆盖平衡性

- 各节引用分布
- 时间分布（近年占比）
- 来源多样性（同一作者/会议/期刊占比）
- 中英文比例（按目标期刊受众）

### 维度 5: 引用恰当性

- 方法/概念的首次提出是否引对了原始文献
- 是否把二手引用当一手
- 基线方法引用是否用了其最新版本

### 维度 6: 缺失检测

- 提到概念/方法/数据集但无引用
- "已有研究表明..."后无标注
- 公式/算法搬用未标来源

## 禁止事项

- ❌ 不自动修正任何引用内容
- ❌ 不自动添加或删除参考文献
- ❌ 不自动修改正文中的引用编号
- ✅ 只输出"发现+建议动作"，等待用户执行

# 论文骨架 — 研究·规划·大纲

本技能覆盖 Stage 1（深度研究）和 Stage 3（搭建骨架）。被「写作工坊」调用。

**绝对不产出论文正文段落。** 所有输出为结构化规划信息。

---

## Stage 1: 深度研究

### 输入

用户选题方向（一句话）+ 可选目标期刊。

### 执行步骤

1. **期刊画像构建** — 联网搜索目标期刊：
   - Aims & Scope、文章类型、格式要求、字数/页数限制、参考文献数量要求
   - 近 1-2 年发表的相似主题论文标题（为 Stage 2 文献检索提供方向）
   - 审稿标准/关注维度（从期刊 editorial 或 published review criteria 推断）

2. **选题边界界定**：
   - In scope / Out of scope / 交叉领域

3. **创新点定位** — 搜索近 2-3 年该方向工作，识别：
   - 已充分研究的子问题（避开）
   - 存在争议的空白（切入）
   - 主流方法的公认局限（机会）

4. **竞争格局分析**：主要竞品方法/系统列表，各自优劣

### 产出格式：`research-notes.md`

```markdown
# 深度研究笔记

## 目标期刊画像
- 期刊名：
- IF / 分区 / CCF：
- 收录范围关键词：
- 格式要求：页数限制、引用体系
- 审稿关注维度：
- 近期同类文章标题：[列表，标记需确认是否真实发表]

## 选题边界
- In scope:
- Out of scope:
- 交叉领域：

## 创新点候选
1. [描述] — 支撑逻辑：
2. ...

## 竞争格局
| 方法/系统 | 核心思路 | 优势 | 局限 |
|...|

## 风险评估
- 本选题在 TOIS 层面的竞争力评估：
- 可能的"不够新"风险点：
- 需要什么样的实验强度才能说服审稿人：
```

## Stage 3: 搭建骨架

### 前置条件

读取 `research-notes.md` + `experiment-plan.md`。

### 执行步骤

1. **选择结构模板** — 根据期刊惯例（如 TOIS 标准结构）

2. **填充各节规划要点** — 对每个节定义：
   - 本节要说服读者什么（一句话）
   - 需要展示的证据类型（实验数据/对比表格/公式推导）
   - 引用的文献范围（从 Stage 2 池中标注编号，全部带 [需核验]）
   - 上下节逻辑衔接点（从X过渡到Y需要回答什么问题）
   - 预期篇幅占比

3. **论证链检查**：
   - 引言提出的问题 → 方法是否都有回应？
   - 方法声称的优势 → 实验是否有对应验证？
   - 实验结论 → 是否限定在数据支撑范围内？
   - 有无"跳步"？

4. **标记风险点**：用 `[⚠️]` 标注容易过度声称/遗漏基线/混淆概念的位置

### 产出格式：`outline.md`

```markdown
# 论文骨架：[暂定标题]

## 基本信息
- 目标期刊：TOIS
- 引用格式：ACM reference format
- 目标页数：XX 页

## 论证主线（一句话）
[问题] → [方法策略] → [验证指标] → [限定结论]

## 章节规划

### 摘要
- 结构：背景→问题→方法→结果→结论
- 字数：150-250 words
- 关键词建议：[5-7个]

### 1. Introduction
- 说服目标：该问题值得研究且现有方案不够
- 需要展示：问题动机 + 现有方案不足 + 本文贡献(编号)
- 引用锚点：[1][2][5][8] (全部 [需用户核验])
- ⚠️ 贡献声明不能是"实现了XX系统"，应是方法论贡献
- 预期占比：10-12%

### 2. Related Work
- 分组策略：按方法/问题维度分 2-4 个子方向
- 每个子方向收束于"这些工作的共同不足→本文如何补"
- 引用锚点：[按分类列出]
- 预期占比：12-15%

### 3. Method / System Design
- 核心设计决策清单（每个决策含"为什么选X不选Y"）
- 形式化定义需求：需要定义什么符号、什么公式
- 预期占比：30-35%

### 4. Experimental Setup
- 参见 experiment-plan.md
- 需要报告的维度：数据集/基线/指标/参数/硬件
- 预期占比：15-20%

### 5. Results & Analysis
- 主实验 + 消融 + 显著性检验
- 需要回答的审稿人预判问题：
- 预期占比：20-25%

### 6. Discussion & Limitations
- 适用边界声明清单
- 不回避的已知弱点

### 7. Conclusion
- 总结（不重复引言）+ 限定声明 + 具体未来工作

## 各节字数分配表
| 章节 | 占比 | 预估字数 |
|------|------|---------|
| ... |

## 图表规划
- 图1：[内容] → 放§X.Y
- 表1：[内容] → 放§X.Y
```

## 禁止事项

- ❌ 不输出任何"段落级"可直接粘贴进论文的文本
- ❌ 不替用户做"本节应该这样论证"的完整文字表述
- ✅ 只输出结构、要点、检查清单、逻辑关系图
